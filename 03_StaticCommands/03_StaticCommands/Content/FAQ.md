# Frequently Asked Questions

## What is DotVVM?

DotVVM is an open-source MVVM framework for web applications that allows you to build interactive web UIs using .NET and C#.

## Is DotVVM free?

Yes! DotVVM is open-source and free to use under the Apache 2.0 license.

## Can I use DotVVM with existing ASP.NET applications?

Absolutely! DotVVM can be integrated into existing ASP.NET Core applications.

## What browsers are supported?

DotVVM supports all modern browsers including:
- Chrome
- Firefox
- Safari
- Edge

## How do I get started?

Check out the official documentation at [dotvvm.com/docs](https://www.dotvvm.com/docs) or explore the tutorial files in this viewer!
